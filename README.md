# Naveen Kumar — Portfolio

A professional, responsive portfolio built with Vite, React, GSAP, and Lucide icons.

## Features

- Responsive desktop, tablet, and mobile layouts
- GSAP entrance and scroll animations
- Particle background, interactive project-card tilt, click ripple, and custom pointer effects
- Local **Ask Navi** portfolio assistant for questions about Naveen's profile, skills, education, internship, projects, achievements, location, and contact details
- Downloadable one-page professional A4 résumé at `public/Naveen_Kumar_Resume.pdf`
- Accessible navigation and reduced-motion support

## Run locally

```bash
npm install
npm run dev
```

## Production build

```bash
npm run lint
npm run build
```

## Regenerate the A4 résumé

The résumé source is in `scripts/generate-resume.mjs`.

```bash
npm run resume
```
